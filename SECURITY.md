# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in ox-codes, please:

1. **DO NOT** open a public issue.
2. Email: **contact@krolik.tools** with subject `[SECURITY] ox-codes: <brief description>`.
3. Include: reproduction steps, affected versions, potential impact.

We aim to respond within 48 hours and patch critical issues within 7 days.

## Supported Versions

| Version | Supported |
|---------|-----------|
| 0.x.x   | active    |

## Disclosure Timeline

- Day 0: Report received, acknowledgement sent
- Day 0-3: Severity assessment + reproduce
- Day 3-7: Patch developed + tested
- Day 7-14: Public disclosure after fix released
